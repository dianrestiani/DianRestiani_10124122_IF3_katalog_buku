# Katalog Buku (PHP + MySQL)

Aplikasi CRUD katalog buku dengan login dan dua bahasa (ID/EN).

## Cara menjalankan
1. Install XAMPP, jalankan Apache dan MySQL.
2. Salin folder ini ke C:\xampp\htdocs\katalog_buku
3. Impor database.sql lewat phpMyAdmin.
4. Buka http://localhost/katalog_buku/login.php
5. Login: admin / admin123
